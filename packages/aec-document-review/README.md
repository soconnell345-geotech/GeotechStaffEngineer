# aec-document-review

An LLM agent that reviews architecture, engineering and construction (AEC)
documents: drawings, specifications and reports, with its findings marked
up on a copy. It is the Document Review page of GeotechStaffEngineer
(`pip install geotech-staff-engineer`), moving into a package of its own,
built on the shared core `aec-agent-core` and the document layer `planlens`.

## Status

**0.1.0.dev0: an empty package.** It holds the name on PyPI and nothing
else; installing it gives you no review page yet. Until the page moves in,
use GeotechStaffEngineer's Document Review page.
