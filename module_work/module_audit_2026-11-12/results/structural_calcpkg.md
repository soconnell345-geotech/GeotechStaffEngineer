## pynite_agent
Size: 4 python files (+ tests), 7 exported names (2 analysis functions, 3 result classes, 2 install checks), 2 adapter methods (frame_analysis, continuous_beam). Small, clean wrapper; the beams are pinned to textbook closed forms. The frame result is thin: it has no node displacements and no 3D member results, and the module has no calc package.
