# Sheet index check: North Yard Annex drawings, issue 1

The index on G-001 lists 16 sheets. The set has 15, and every title block reads "SHEET n OF 15". Two things don't match:

1. **A-202 INTERIOR ELEVATIONS (rev 0) is listed but is not in the set.** No sheet A-202 exists; the set goes from A-201 (sheet 6) to A-301 (sheet 7). Either add the sheet or delete the index entry.
2. **S-201 has the wrong title in the index.** The index calls it "ROOF FRAMING PLAN", but the sheet's title block and view title say "SECOND FLOOR FRAMING PLAN". S-202 is the roof framing plan, so the index now lists two "ROOF FRAMING PLAN" sheets.

All the other entries match the sheets in sheet number, title and order: G-001, G-002, C-101, A-101, A-102, A-201, A-301, A-401, A-501, A-601, S-001, S-101, S-202 and S-501.

The REV column matches each sheet's own revision block: G-001, A-401 and A-601 are at rev 1 and the rest at rev 0. One related point: S-001's content changed in this issue (note 2, bearing pressure) without a revision being recorded, so the "0" for S-001 is consistent with the sheet but probably should be 1. This is covered under the revisions review.
